Crop Failure Network

A crop failure diagnosis with the same structure as the classic Asia network. Click a node to set it true, then false, then unknown. Every other node shows P(true) given the evidence, and ▲/▼ shows how far it moved after your last change. The probabilities are illustrative, not real agronomy data.

Conditional probability tables

Each row gives P(variable = true) for one combination of its parents. Edit any value to see how the numbers change. The d-separation results (where a node shows “no change”) hold no matter what values you enter.
